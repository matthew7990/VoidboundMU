# VoidboundMU

**MU Online private server — custom client launcher**

## Para jugar

1. Descargá el cliente desde [Releases](https://github.com/matthew7990/VoidboundMU/releases/latest)
2. Descomprimí el ZIP en cualquier carpeta
3. Ejecutá `MuVoidLauncher.exe`
4. Esperá que el launcher actualice los archivos
5. Presioná **PLAY**

> **Requisito:** [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)

## Para administradores — publicar un update

```bat
release_client.bat 1.00 "Descripcion del cambio"
```

Requiere [GitHub CLI](https://cli.github.com/) instalado y autenticado.
